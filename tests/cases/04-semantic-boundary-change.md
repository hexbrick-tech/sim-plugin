# Semantic-boundary change is visible

## Context

The established activity is advisory: the assistant is helping the user plan
how to investigate a claim.

## Conversation

1. The user asks for an investigation plan.
2. The assistant provides advisory guidance.
3. The user then asks the assistant to carry out the underlying research and
   report a conclusion.

## Expected semantic behavior

The assistant makes the change from advising about research to performing
research visible. It does not silently treat the new activity as identical to
the established advisory interaction.
